# 小程序开发规范

当前只开发第一套外观。首页入口是 `pages/index/index.vue`，渲染 `pages/index/components/home_first.vue`。首页以[首张参考截图](外观参考/第一套/首页/初始状态.jpg)和本地 Mock 数据还原。全项目使用正常字号，字体和布局尺寸使用 `rpx`，不提供字号切换。

## 本地运行

用 HBuilderX 打开仓库的 `miniapp/` 目录，选择「运行 → 运行到小程序模拟器 → 微信开发者工具」。工程使用 HBuilderX 自带的 uni-app Vue 3 编译器。微信开发版产物在 `unpackage/dist/dev/mp-weixin/`。首次使用可在微信开发者工具的安全设置中开启服务端口。

第一套静态页可通过底栏查看首页、预约挂号和个人中心。预约挂号可切换「按科室」「按日期」「按医生」对照三张截图。未登录时，在「专家团队」点任意医生卡片上的任意位置，授权登录页从右侧滑入，点返回回到原列表。

从首页点「预约挂号」切换到底栏并选中「按科室」。点「专家团队」或「我的预约」可免登录进入对应的二级页，点返回回到首页。外观分别见[医生列表](外观参考/第一套/医生/初始状态.jpg)和[预约记录空状态](外观参考/第一套/预约记录/空状态.jpg)。首页轮播支持横滑，多张素材时自动轮播，点击图片停留在首页。

微信 AppID 填在 `manifest.json` 的 `mp-weixin.appid`。初始化阶段留空，后续真机预览和发布时使用本项目对应的 AppID。
