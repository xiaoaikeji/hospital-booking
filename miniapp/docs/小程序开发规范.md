# 小程序开发规范

当前只开发第一套外观。首页入口是 `pages/index/index.vue`，渲染 `pages/index/components/home_first.vue`。收到截图后先完成静态页面。全项目使用正常字号，字体和布局尺寸使用 `rpx`，不提供字号切换。

| 本次要做什么 | 读哪份规范 |
| --- | --- |
| 建页面、改路由、拆组件、命名、引入依赖或接接口 | [工程与代码](工程与代码.md) |
| 复刻外观、做图片、取图标或管理资源 | [外观与素材](外观与素材.md) |
| 根据截图做首版、确认交互、验收页面 | [复刻步骤与验收](复刻步骤与验收.md) |

遇到不明确的细节，向负责人问清后再实现。负责人的当次明确要求与项目规范冲突时，指出具体条款、差异和本次处理方式，按当次要求执行。长期规范是否修改由负责人决定。

## 本地运行

用 HBuilderX 打开仓库的 `miniapp/` 目录，选择「运行 → 运行到小程序模拟器 → 微信开发者工具」。工程使用 HBuilderX 自带的 uni-app Vue 3 编译器。微信开发版产物在 `unpackage/dist/dev/mp-weixin/`。首次使用可在微信开发者工具的安全设置中开启服务端口。

微信 AppID 填在 `manifest.json` 的 `mp-weixin.appid`。初始化阶段留空，后续真机预览和发布时使用本项目对应的 AppID。
