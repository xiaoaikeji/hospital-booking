# 外观与素材

- 按对应款式的原页面还原结构、字体大小、颜色、间距、图片裁切和滚动效果。尺寸使用 `rpx`，按正常字号对照。顶部避开微信胶囊，底部固定按钮为安全区和最后一项内容留空间。
- 返回、搜索、箭头、勾选等通用单色图标优先从阿里巴巴矢量图标库 Iconfont 选取。先查项目已有图标；缺少时由开发者按原图的线条、圆角和风格自行查找、下载可用于本项目的图标，整理为本地字体和有含义的类名。扩充时保留已有字形编码。找不到合适的单色图标时可参照原图重绘 SVG 后加入字体。
- 复刻所需的 Banner、插画、装饰图按参考图自行生成。目标是放回页面后与原版一致，按相同屏宽对照构图、文字、比例、色彩和裁切，有差异就调整。多色或品牌专用图标按独立图片还原。真实身份或品牌素材辨认不清时先问负责人。
- 桶和 CDN 尚未准备好。运行时的字体、图片统一放 `static/`，按用途分，如 `static/tabbar/`、`static/home/`。图片按展示尺寸压缩。将来可把适合远程加载的内容图迁移到 CDN，TabBar 图标等需要立即显示的资源继续放本地。
- 页面原截图、录屏、设计稿按款式、页面和状态放在 `docs/` 下对应的参考目录。实际用于页面渲染的素材才放进 `static/`。
