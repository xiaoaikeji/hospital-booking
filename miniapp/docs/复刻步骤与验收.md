# 复刻步骤与验收

1. **收集参考。** 负责人先提供页面截图，也可以补充设计稿、录屏、原图等资料。负责人在 Mac 微信登录并指定目标后，开发者可打开对应小程序，操作、截图和记录状态。画面被遮挡、文字无法辨认或缺少关键区域时，先问清楚。
2. **先交付完整静态页。** 数据使用截图里的名称、日期、价格和状态，作为本地 Mock。先还原整页及已有素材里的状态，包括首屏以下内容。按相同屏宽在微信环境对照原版，校正图片和布局，交负责人确认。
3. **逐项确认交互。** 静态效果确认后，开列具体控件，逐项询问“点哪里、发生什么、怎么返回”。负责人操作原版并回答后，再实现相应行为。无法触发的状态标为待确认。此阶段可继续用 Mock；真实接口按后续需求接入。
4. **按本页需要验收。** 对照滚动、吸顶、弹层、固定底栏和按钮点击区域。从详情返回列表保留筛选及滚动位置，数据变更后更新相关内容。区分加载失败、空数据和已约满。涉及预约提交时防重复点击，接入真实接口后以服务端结果为准。

在微信开发者工具核对当前款式和 Mock 数据。涉及真机特有的授权、键盘或安全区表现时，补对应的真机检查。按本项目正常字号验收。
