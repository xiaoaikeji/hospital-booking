# 本地运行

## 管理后台

需要 Ruby 3.4.12、Bundler、PostgreSQL、Redis 和 ImageMagick。启动 PostgreSQL 和 Redis，从仓库根目录进入后端并安装依赖。

```sh
cd backend
bundle install
```

在本机创建 `backend/config/database.yml`。例如，使用当前系统用户连接本机 PostgreSQL 时可以这样填写。需要用户名和密码的环境，也可以通过 `DATABASE_URL` 提供当前环境的连接。

```yaml
development:
  adapter: postgresql
  database: booking_web_development

test:
  adapter: postgresql
  database: booking_web_test
```

全新安装时，先执行 `bin/rails credentials:edit`，按编辑器提示保存退出，以生成本机的加密凭据和解密密钥。如果迁移已有数据库，请使用与之配套的原密钥。在同一终端继续执行以下命令。

```sh
bin/rails db:prepare
bin/rails settings:encryption_keys
bin/rails admin:create
bin/rails dartsass:build
bin/dev
```

打开 [后台登录页](http://localhost:3000/admins/sign_in)。默认首个账号是 `admin`，密码是 `123456`。可在执行 `admin:create` 前通过 `ADMIN_USERNAME` 和 `ADMIN_PASSWORD` 指定初始账号密码。已有管理员时，该命令保留原账号。

另开终端，在 `backend/` 运行 `bin/jobs` 启动后台任务。开发环境默认使用本机 Redis（`redis://localhost:6379/0`）和本地文件存储；若本机还有其他项目共用 Redis，建议为 Booking 的 Web 和 `bin/jobs` 统一指定独立的 `REDIS_SIDEKIQ_URL`（如单独的逻辑库或 Redis 实例）。

## 微信小程序

1. 在 HBuilderX 中打开仓库的 `miniapp/` 目录。
2. 选择「运行 → 运行到小程序模拟器 → 微信开发者工具」。首次使用时可在微信开发者工具设置中开启服务端口。
3. 在模拟器中查看首页、预约挂号和个人中心。需要真机预览时，在 `miniapp/manifest.json` 的 `mp-weixin.appid` 填入自己的小程序 AppID。

### 联调页面配置

在「应用管理 → 应用列表」登记并启用该微信 AppID。全新数据库的 `db:prepare` 会初始化一张通用轮播图和三个「我的」菜单。升级已有数据库时，在 `backend/` 执行 `bin/rails db:migrate` 和 `bin/rails db:seed`。初始化标记保存在数据库中，重复执行会保留管理员的修改和删除。

在 `miniapp/.env.local` 填写 `VITE_BOOKING_API_ORIGIN=http://127.0.0.1:3000`，重新编译微信小程序。仅在本机模拟器调试 HTTP 时，使用开发者工具的「不校验合法域名」选项。后台地址留空或使用游客 AppID 时，页面使用本地素材预览。

超级管理员在「应用管理 → 小程序页面配置」选择通用配置或某个微信小程序，再选「首页轮播」或「我的菜单」。小程序冷启动后读取配置。网页链接需在各使用该链接的小程序中登记 HTTPS 业务域名，客服使用微信公众平台配置的小程序客服。内部页面支持专家团队、预约记录、意见反馈和医院介绍，底部 Tab 支持首页、预约挂号和「我的」。

后端部署所需的环境变量见[部署与配置](部署与配置.md)。

本地验证微信配置时，用超级管理员在「应用管理 → 应用列表」按平台和类型创建演示账号。真机回调需要微信可访问的 HTTPS 部署。公众号配置、升级交接和小程序上传发布步骤见[部署与配置](部署与配置.md)。
