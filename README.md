# 小艾预约挂号系统

单机构预约挂号项目，包含 Rails 管理后台和微信小程序，目前仍在开发中。

| 工程 | 当前功能 |
| --- | --- |
| [管理后台与服务端](backend/) | 管理员与角色权限、系统设置、操作日志、小程序应用管理和微信版本提审发布。预约管理仍有演示页面。 |
| [微信小程序](miniapp/) | 使用 uni-app 和 Vue 3。当前可浏览首页、医生与预约挂号页面，页面使用本地示例数据。 |

## 运行与使用

- 首次下载项目，从[本地运行](docs/setup/本地运行.md)开始，包含后端初始化、首次登录与小程序预览。
- 部署后端、配置 Redis 或启用腾讯云 COS，见[部署与配置](docs/setup/部署与配置.md)。

登录后台后，超级管理员可在「系统设置」维护存储和默认外观，在「应用管理」配置小程序并管理微信版本。运营管理员和客服可查看本人的操作记录，所有管理员均可修改自己的密码和外观。
