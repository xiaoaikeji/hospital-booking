# 后台样式规范目录

先查 [公共组件](../app/views/admins/shared/) 和 [公共布局](../app/views/layouts/admins.html.erb)。没有合适的，再按下面的用途选择，只读需要的分组。

预览入口：[/admins/components](http://192.168.1.21:3000/admins/components)。示例代码位于 `app/views/admins/components/`。

- [图片与附件](admin-ui/media.md)：封面、多图、列表小图、放大预览、头像、附件。
- [输入与校验](admin-ui/forms.md)：文本、金额、单位、日期、配置来源、必要提示、错误显示。
- [选择与开关](admin-ui/selection.md)：下拉、单选、多选、开关、权限勾选。
- [列表与状态](admin-ui/records.md)：ID、手机号、状态标签、空列表、分页。
- [反馈与加载](admin-ui/feedback.md)：成功/失败提示、Toast、加载、进度、骨架。
- [导航与布局](admin-ui/containers.md)：公共页面框架、配置表单、栅格、页签、折叠、抽屉。
- [操作与确认](admin-ui/actions.md)：按钮颜色与尺寸、更多操作、删除与风险确认。

需要找桌面原文件或素材来源时，再看 [材料索引](admin-ui/sources.md)。
